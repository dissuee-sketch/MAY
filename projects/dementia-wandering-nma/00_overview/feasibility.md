# 可行性評估（Feasibility）——先做這一步，再投入時間

> meta-pipe 規定：任何統合分析開始前，**一定要先做約 4 小時的可行性評估**，避免做了 40 小時才發現沒有足夠文獻。

## 1. PubMed 初步試搜結果（2026-11-03）

| 搜尋組合 | 筆數 | 白話解讀 |
|---|---|---|
| 失智 + 遊走 + 隨機（randomized） | **55 筆** | 這是「最寬鬆」的數字，裡面很多其實不是針對遊走的 RCT |
| 失智 + 遊走 + 系統性回顧 | 45 筆 | 已有回顧多半談 BPSD 整體，**尚未找到專門針對遊走的 NMA** → 有研究缺口 |

搜尋式見 `02_search/round-01/queries.txt`。

### 這代表什麼？（白話）
- **好消息**：專門比較「各種非藥物措施對遊走」的網絡統合分析（NMA）目前 PubMed 上找不到，代表題目有**新穎性**。
- **壞消息**：真正以「遊走」為主要結果的 RCT 很少。過去的回顧文獻（如 Cochrane）也常提到這個領域 RCT 不足。
- **NMA 的最低門檻**（本專案自訂）：主要結果至少 **10 篇 RCT**、且網絡要**連通**（每個措施都能透過共同比較組連起來）。

## 2. 決策關卡（篩選完成後判斷）

```
篩選後，主要結果的 RCT 有幾篇？
│
├─ ≥10 篇且網絡連通 ───────────▶ Plan A：照原計畫做 NMA（目標 Ageing Res Rev）
│
├─ 5–9 篇，或網絡不連通 ───────▶ Plan B：
│                                  ① 擴大結果為「遊走 + 激躁（agitation）」或 BPSD 中的運動行為
│                                  ② 或改做 pairwise 統合分析（各措施 vs 一般照護，分組分析）
│                                  ③ 納入類實驗研究，但與 RCT 分開分析
│
└─ <5 篇 ──────────────────────▶ Plan C：改做 Scoping review（範圍回顧）
                                   不做合併計算，整理「有哪些措施、證據缺口在哪」
                                   一樣可以投稿（如 JBI Evidence Synthesis、Geriatric Nursing）
```

> 給長官的說法：「我們已預先設定三種路線與轉換條件，並寫進研究計畫書（PROSPERO），不會因結果不如預期而臨時改方法。」——這是審查委員最在意的「事先規劃」。

## 3. 可行性檢核表

- [x] PubMed 初步試搜（55 筆，可行性：中低）
- [ ] 查 PROSPERO 是否已有人註冊相同題目（https://www.crd.york.ac.uk/prospero/）
- [ ] CINAHL 試搜（護理研究多收錄在這裡，數量可能比 PubMed 多）
- [ ] 中文資料庫試搜（華藝 Airiti、CNKI）——台灣與中國大陸護理期刊有不少介入研究
- [ ] 快速瀏覽前 50 筆標題，估計「真正 RCT + 有遊走結果」的篇數
- [ ] 找第二位審查者（雙人篩選必需）：建議病房內一位學士以上護理師或研究部同仁
- [ ] 找統計協助（研究部 / 醫學研究部統計諮詢）
- [ ] 依結果決定 Plan A / B / C，記錄在 `01_protocol/decision-log.md`
