# 納入與排除條件（Eligibility Criteria）

> 用途：兩位審查者篩文獻時「一模一樣」照這張表判斷，才能算出可信的一致性（Kappa）。

## 納入條件（全部符合才納入）

| 項目 | 條件 |
|---|---|
| P 對象 | 診斷失智症（任何類型、任何嚴重度）；混合樣本中失智者 ≥80% |
| I 介入 | 任何非藥物措施（見 `pico.yaml` 的 7 類節點） |
| C 比較 | 一般照護、等候名單、注意力控制組，或另一種非藥物措施 |
| O 結果 | 至少報告一項：遊走頻率／嚴重度、走失／離院事件、跌倒、激躁、照顧者負荷、生活品質、約束使用 |
| S 設計 | RCT（含群集隨機、交叉設計） |
| 語言 | 英文、中文 |

## 排除條件與代碼（篩選表單直接填代碼）

| 代碼 | 排除原因 |
|---|---|
| E1 | 對象不是失智症（或失智者 <80%） |
| E2 | 藥物介入，或非藥物 + 藥物無法分開 |
| E3 | 沒有比較組（單組前後測） |
| E4 | 非 RCT（觀察性、類實驗）※Plan B 時改為「保留另案」 |
| E5 | 沒有任何符合的結果指標 |
| E6 | 文章類型不符（回顧、評論、研究計畫書、只有摘要沒有數據） |
| E7 | 重複發表（保留樣本數最完整的那篇） |
| E8 | 無法取得全文 |

## 判斷原則
1. **標題摘要階段**：「不確定」一律先放行（include/maybe），到全文階段再判斷。
2. 兩人意見不同 → 討論；仍不同 → 第三人（建議請督導或研究部老師）裁決。
3. 每個排除決定都要填代碼，PRISMA 流程圖會用到。
