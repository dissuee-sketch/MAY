# SARC-CalF 測量標準作業（SOP）

> 目的：讓每位收案護理師**量法一模一樣**，數據才可信。長官和審查委員最常問的就是「怎麼確保大家量得一樣？」

## 一、SARC-F 問卷（問「入院前 2 週」的狀況）

| 題目 | 問法 | 0 分 | 1 分 | 2 分 |
|---|---|---|---|---|
| S 肌力 | 提起或搬動約 4.5 公斤（一袋 5 公斤米）有多困難？ | 沒困難 | 有些困難 | 很困難／做不到 |
| A 行走輔助 | 走過一個房間有多困難？ | 沒困難 | 有些困難 | 很困難／需輔具／做不到 |
| R 從椅子站起 | 從椅子或床上站起來有多困難？ | 沒困難 | 有些困難 | 很困難／需他人協助 |
| C 爬樓梯 | 爬 10 階樓梯有多困難？ | 沒困難 | 有些困難 | 很困難／做不到 |
| F 跌倒 | 過去一年跌倒幾次？ | 0 次 | 1–3 次 | ≥4 次 |

- 優先由病人本人回答；認知不佳時由**主要照顧者**回答，並記錄資料來源（`baseline_source`）。

## 二、小腿圍測量

| 項目 | 規定 |
|---|---|
| 工具 | 不具彈性的軟皮尺，刻度到 0.1 cm |
| **時機** | **透析後 24 小時內**（體液最接近乾體重）；若入院 48 小時內沒有透析，就在入院 48 小時內量，並註記 |
| 姿勢 | 坐姿，膝蓋與腳踝彎曲 90 度，雙腳平放地面；無法坐時採仰臥、屈膝 90 度，並記錄姿勢 |
| 位置 | 小腿**最粗處**，皮尺上下移動找最大值，皮尺貼皮膚但不壓陷 |
| 側別 | 優先量**無水腫、無傷口**的一側，記錄左或右（`calf_side`） |
| 次數 | 量 **2 次**取平均；兩次差距 >0.5 cm 就量第 3 次，取最接近的兩次平均 |
| 水腫 | 按壓脛骨前側，記錄凹陷性水腫等級 0／1+／2+／3+／4+（`calf_edema`） |
| 切點 | 男性 <34 cm、女性 <33 cm → SARC-CalF 加 10 分 |

## 三、計分

```
SARC-CalF = SARC-F 總分（0–10）＋ 小腿圍分數（0 或 10）
≥11 分 → 陽性（肌少症風險）
```

**白話**：小腿圍低於切點就直接加 10 分，所以「小腿細 + SARC-F 有任何 1 分」就是陽性；小腿圍正常的人，SARC-F 最高 10 分，永遠不會陽性。

## 四、施測者訓練與一致性（龜毛長官必問）

1. 收案前由主持人帶所有施測護理師上課 1 小時，並實際練習。
2. **一致性測試**：2 位施測者各自量同一批 10–15 位病人的小腿圍，計算**組內相關係數（ICC）**，目標 **≥0.90**。
3. ICC 結果寫進論文方法段，例如：「施測者間信度 ICC = 0.95」。

> ICC 白話：0 到 1 之間的數字，越接近 1 代表兩個人量得越一致。0.9 以上算「極佳」。
