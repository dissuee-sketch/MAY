# SARC-CalF 篩檢與高齡血液透析病人住院相關失能

**高齡血液透析病人入院時 SARC-CalF 篩檢與住院期間日常生活功能下降之相關性：前瞻性世代研究**

| 項目 | 內容 |
|---|---|
| 研究類型 | 原創研究：前瞻性世代研究（STROBE 指引） |
| 場域 | 台中榮總急診後送病房 |
| 對象 | ≥65 歲、規律血液透析 ≥3 個月、經急診入院 |
| 樣本數 | 200 人 |
| 主要結果 | 住院相關失能（HAD）：出院時巴氏量表比入院前 2 週下降 ≥5 分 |
| 建立日期 | 2026-11-03 |

> 這是**原創研究**，自己收病人資料，所以**不適用 meta-pipe**（meta-pipe 只做彙整已發表文獻的統合分析）。這裡借用它「分資料夾、留紀錄、逐步檢核」的管理方式。

---

## 一句話說明

**入院時用 3 分鐘、一條皮尺做肌少症篩檢，能不能預先找出「住院後會變得更不能自理」的透析長者？**

## 給長官的一頁摘要

| 問題 | 回答 |
|---|---|
| **為什麼做？** | 透析長者住院後常「病好了、人卻不能走了」，延長住院、增加照護人力與轉機構率 |
| **有沒有人做過？** | PubMed 上 SARC-CalF 用於透析的研究共 10 篇，都在門診，**沒有一篇看住院期間的功能下降** |
| **病房做得到嗎？** | 不需要額外儀器，只要一條皮尺加 5 題問卷，護理師入院評估時 3 分鐘可完成 |
| **方法夠嚴謹嗎？** | 前瞻性設計、標準化 SOP、施測者一致性檢測（ICC ≥0.90）、樣本數有計算依據、多變項校正干擾因子、敏感度分析 |
| **做完有什麼用？** | 證實有預測力 → 建立「SARC-CalF 陽性 → 早期活動＋照會復健」流程 → 下一步做介入研究 |
| **風險？** | 最小風險研究，只有問卷和量尺，不影響治療 |

## 下一步（照順序）

1. 請長官和共同主持人（建議：腎臟科醫師、復健科或營養師）看過計畫書
2. 到台中榮總研究部，用 IRB 最新表單改寫計畫書
3. 訓練收案護理師並完成 ICC 一致性測試
4. IRB 通過後開始收案
